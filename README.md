# 🧠 智汇中枢 (ZhihuiZhongshu)

**AI 驱动的智能知识工作台** —— 本地部署的桌面应用，集知识库管理、智能对话、数据分析、AI 可视化大屏于一体。

> 所有数据仅保存在你本地电脑，无需部署服务器，配置好 API 密钥即可使用。

---

## ✨ 功能特性

| 功能 | 说明 |
|------|------|
| 💬 **智能对话** | 接入 DeepSeek / OpenAI / Kimi 等大模型，**流式输出**逐字显示 |
| 📚 **知识库管理** | 上传 xlsx/csv/pdf/docx/图片/PPT 等自动解析，知识库 → 文件夹 → 文件三级管理 |
| 🖥️ **AI 可视化大屏** | **核心亮点**：根据上传数据自动生成 HTML 大屏，**不固定模板**，可对话式优化调节 |
| 📊 **图表生成** | 柱状 / 折线 / 饼图 / 雷达 / 热力 / 仪表盘等 12+ 种图表 |
| 📄 **报告 / PPT** | 自动生成结构化分析报告，一键生成演示文稿 |
| 🔍 **联网搜索** | 内置 Bing 搜索，AI 自动联网获取最新信息 |
| 🔄 **多会话并发** | 多个会话同时提问互不干扰，各自独立回复 |
| 📤 **配置导出** | 模型配置一键导出为可读文本文件 |
| 🗑️ **回收站** | 误删可恢复 |

## 🖥️ 可视化大屏（亮点功能）

只需要在对话中说 **"生成大屏"**，AI 就会：

1. **自动分析你上传的表格数据结构**（列名、数值、分类）
2. 自主决定大屏的**布局、组件、配色**（不套用任何固定模板）
3. 生成**自包含的 HTML 大屏**，自动用浏览器打开 + 给出本地链接
4. 继续对话即可**优化调节**：「把主题改成浅色」「柱状图换成折线」「加个渠道占比饼图」→ 生成新版本

支持 **16 种组件**：KPI 数字卡片、柱状图、折线/面积图、饼图/环图、雷达图、散点图、热力图、仪表盘、漏斗图、排名列表、数据表格、标题文本等。

每个版本都会**留档**，可在「可视化大屏」页面随时重新打开、查看/回退历史版本。

## 🚀 快速开始

### 方式一：一键脚本（推荐）

**Windows** —— 双击运行 `start_windows.bat`
> 首次运行会自动创建虚拟环境并安装依赖（约 3~5 分钟），之后双击即启动。

**macOS** —— 终端执行：
```bash
chmod +x setup_mac.command
./setup_mac.command
```

### 方式二：手动安装

```bash
# 克隆项目
git clone https://github.com/zimu645-dotcom/zhihuishuzhongshu.git
cd zhihuishuzhongshu

# 创建虚拟环境并安装依赖
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS / Linux:
source venv/bin/activate

pip install -r requirements.txt

# 启动
python main.py
```

## ⚙️ 首次配置（必做）

启动后，**左侧导航 → 大模型配置**：

1. 填入你的 **API 密钥**（DeepSeek / OpenAI 等，不同能力可配不同模型）
2. 点击 **💾 保存配置**
3. 点击 **🧪 测试连接** 验证

> 获取 DeepSeek API 密钥：https://platform.deepseek.com （注册后创建 API Key）

未配置密钥时，AI 会提示"未配置模型"，配置后即可正常对话。

## 📖 使用指南

**1. 建立知识库**
左侧导航 → 知识库 → 新建知识库 → 上传文件（支持 xlsx/csv/pdf/docx/txt/图片等）

**2. 智能对话**
会话页顶部选择知识库/文件夹/文件 → 输入问题 → AI 基于所选内容回答

**3. 生成可视化大屏**
会话页选中一个 **xlsx/csv 表格文件** → 输入 `生成销售数据大屏`（或"数据看板"）

**4. 优化大屏**
继续输入：`把主题改成浅色` / `加一个渠道占比饼图` → 生成新版本，历史版本在「可视化大屏」页可回退

**5. 导出配置**
「大模型配置」页 → `📤 导出配置文件` → 得到可读的 JSON 文本文件

## ❓ 常见问题

**Q: 提示"未配置模型"？**
去「大模型配置」页填写 API 密钥并保存。

**Q: 大屏打开后图表空白？**
首次生成大屏需要联网下载一次 ECharts 图表库（约 1MB，会自动缓存）；若本地已有缓存或使用 CDN 则不受影响。

**Q: 本地服务端口被占用？**
大屏链接使用 `http://127.0.0.1:8756`，被占用时自动换端口，无需处理。

**Q: 支持哪些文件格式？**
xlsx / csv / pdf / docx / pptx / txt / md / 图片(png/jpg等) / json。

**Q: 会不会上传我的数据到云端？**
不会。本项目完全本地运行，仅在你提问时把**你主动选择的文件内容**发送给模型 API 用于回答，其余数据不出本机。
